# Reference analysis and originality boundary

## Observed reference

The user supplied [Polski Piłkarz Simulator v1.45](https://www.tetrycy.com.pl/polskipilkarzsimulator/1.45/), viewed on 2026-10-04. Its page presents character setup, a career dashboard, a button to advance a season, career history, a final season-by-season summary, options, and local save controls. The official [getting-started guide](https://polskipilkarzsimulator.pl/jak-grac/) describes creating a player, choosing a first club, playing seasons, development, transfers, and later opportunities. These observations support the **structure** of a choice-driven career loop; they do not establish its internal formulas.

## Translation into an original game

| Reference pattern | Proposed streamer-game interpretation |
| --- | --- |
| Create a footballer | Create a streamer persona and channel focus |
| Advance one season | Plan and resolve one streaming week |
| See performance and career stats | See a weekly report and a persistent channel dashboard |
| Receive career opportunities | Decide on sponsors, collaborations, and investments |
| Review career history | Review a chronological week log and annual recap |
| Save on device | Keep versioned career saves in the player's browser |

The streamer game needs its own pacing, metrics, formulas, events, voice, UI design, branding, and code. Do not reuse source text, visual assets, logos, data tables, or implementation from the reference. Any later comparison should cite the specific public page and distinguish verified observations from design proposals.
