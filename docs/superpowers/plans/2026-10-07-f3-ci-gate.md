# F3 CI Build and Test Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a GitHub Actions workflow that, on every push and on every pull request into `main`, checks formatting, builds in Release, runs all tests, and builds and starts the production container.

**Architecture:** One new workflow, `.github/workflows/ci.yml`, with two parallel jobs. `build-and-test` runs the `dotnet` gate from `PolskiStreamerSymulatorApp/`. `container` builds `deploy/Dockerfile`, starts the image, and probes `/health/live`, `/health/ready`, and `/`. `deploy.yml` stays unchanged. Verification is layered:

1. `actionlint`;
2. a clean-clone rehearsal of both jobs, including two deliberate failures;
3. the first real run on GitHub for the pushed feature branch.

**Tech Stack:** GitHub Actions on `ubuntu-latest`, `actions/checkout` and `actions/setup-dotnet` pinned by SHA, .NET 10 SDK through `global.json`, Docker Buildx, curl, and `actionlint` 1.7.12.

**Spec:** `docs/superpowers/specs/2026-10-07-f3-ci-gate-design.md`

## Review Focus

1. **A container that builds but cannot start must fail the gate.** This is F1's wrong-entrypoint class. Owned by Task 1, Step 8: a clone with a broken `ENTRYPOINT` must fail the liveness wait.
2. **A 200 response that is not the client page must fail the page check.** For example, a host that serves only health text. Owned by Task 1, Step 7: the marker check against `/health/live` must exit with code 1.
3. **The test step must run the real suite, not zero tests.** Owned by Task 1, Step 5 (`total: 195` in the clean clone) and Task 3, Step 4 (`total: 195` in the GitHub log).
4. **A pushed branch must get a CI run for its exact commit.** Owned by Task 3, Step 2: the run's `headSha` equals the pushed `HEAD`, and its event is `push`.
5. **Formatting that passes on Windows must also pass on the Linux runner.** Owned by Task 3, Step 3: the `Check formatting` step is green on GitHub.

**Interfaces:**

- [ ] **Step 1: Write the workflow**

Create `.github/workflows/ci.yml`:

```yaml
name: CI

on:
  push:
    branches:
      - '**'
  pull_request:
    branches:
      - main

permissions:
  contents: read

concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true

jobs:
  build-and-test:
    name: Build and test
    runs-on: ubuntu-latest
    timeout-minutes: 15
    defaults:
      run:
        working-directory: PolskiStreamerSymulatorApp
    steps:
      - name: Check out exact commit
        uses: actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683 # v4.2.2
        with:
          persist-credentials: false
      - name: Install .NET SDK
        uses: actions/setup-dotnet@67a3573c9a986a3f9c594539f4ab511d57bb3ce9 # v4.3.1
        with:
          global-json-file: PolskiStreamerSymulatorApp/global.json
      - name: Restore
        run: dotnet restore PolskiStreamerSymulatorApp.sln
      - name: Check formatting
        run: dotnet format PolskiStreamerSymulatorApp.sln --verify-no-changes --no-restore
      - name: Build
        run: dotnet build PolskiStreamerSymulatorApp.sln -c Release --no-restore
      - name: Test
        run: dotnet test --solution PolskiStreamerSymulatorApp.sln -c Release --no-build

  container:
    name: Container image
    runs-on: ubuntu-latest
    timeout-minutes: 15
    steps:
      - name: Check out exact commit
        uses: actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683 # v4.2.2
        with:
          persist-credentials: false
      - name: Build image
        run: docker buildx build --platform linux/amd64 --file deploy/Dockerfile --tag "pss-ci:$GITHUB_SHA" --load .
      - name: Start container
        run: docker run --detach --name pss-ci --publish 8080:8080 "pss-ci:$GITHUB_SHA"
      - name: Wait for liveness
        run: curl --fail --silent --show-error --output /dev/null --retry 30 --retry-delay 1 --retry-all-errors http://localhost:8080/health/live
      - name: Check readiness and client page
        shell: bash
        run: |
          set -euo pipefail
          curl --fail --silent --show-error --output /dev/null http://localhost:8080/health/ready
          body=$(curl --fail --silent --show-error http://localhost:8080/)
          grep --fixed-strings --quiet '<div id="app">' <<< "$body"
      - name: Print container logs
        if: failure()
        run: docker logs pss-ci
```
